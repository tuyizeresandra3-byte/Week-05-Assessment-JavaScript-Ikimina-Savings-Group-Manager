Project name: Ikimina Savings Group Manager

## Project Description

This project is part of my Week 05 JavaScript. It demonstrates my understanding of JavaScript fundamentals, variables, strings, numbers, conditions, loops, functions, callbacks, and testing.

The program manages an example community savings group by calculating member contributions, determining savings status, formatting amounts in Rwandan francs (RWF), and generating a group savings report.

## Assessment Parts

### Part A: Knowledge and Debugging
- Predict JavaScript outputs.
- Identify and fix errors in a loop.
- Explain variables, functions, and loops.

### Part B: Variables, Strings and Numbers
- Clean and format member names.
- Generate initials.
- Mask phone numbers.
- Convert strings to numbers.
- Calculate yearly savings and interest.

### Part C: Conditions and Loops
- Calculate member contributions using loops.
- Determine savings status using conditions.
- Convert membership levels using a switch statement.
- Display savings bars and group statistics.
- Calculate the estimated weeks needed to reach a savings goal.

### Part D: Functions and Problem-Solving
- `formatRwf()` — formats amounts in Rwandan francs.
- `maskPhone()` — masks valid phone numbers.
- `memberTotal()` — calculates total contributions.
- `getStatus()` — determines savings status.
- `loanLimit()` — calculates the loan limit.
- `isOnTrack()` — checks whether a member is on track.
- `countMembers()` — counts members using a callback.
- `printReport()` — prints the savings report.

### Part E: Code Quality, Testing and GitHub
- Use `const` and `let` appropriately.
- Use strict equality comparisons (`===`).
- Write readable code with consistent indentation.
- Test the Part D functions.
- Maintain meaningful Git commit history.
